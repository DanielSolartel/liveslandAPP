# LIVE (identificador provisional)

Plataforma de transmisiones en vivo y monetización de creadores, con contenido para adultos y un casino previsto desde el lanzamiento. El primer mercado es Colombia.

**Etapa actual: definición e investigación.** La aplicación todavía **no está implementada**: este repositorio solo contiene documentación. La investigación de viabilidad LIVE-001 sigue abierta.
